# Milestone 9, Kiosk Mode: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On shared family screens, PlanaVista hides Home Assistant's menus (the sidebar, and the top bar or all of it but its tabs), a parent whose own Home Assistant login is an admin can step out from the parent strip for as long as parent mode would last, and an admin can turn it off from their own phone. The branch also carries release 1.6.0's version and docs.

**Architecture:** see the design, section 3 (`docs/superpowers/specs/2026-10-12-kiosk-mode-design.md`). The backend stores the setting (`household/kiosk.py` rules, `store.py`, `websocket.py`) and decides who may step out (`pin/unlock`'s `may_exit_kiosk`, `planavista/kiosk/exit`). The card's bundle starts a page-wide controller (`shell/kiosk-controller.ts`) that turns on Home Assistant's own kiosk switch and adds a style to the dashboard's root; its rules are pure (`core/kiosk.ts`) and it reaches the page only through a small `KioskEnv`, so unit tests fake it. The card adds the strip's button (its strip and Settings' alike), the Settings controls, and the room under the status bar.

**Tech Stack:** TypeScript 5.7 with Lit 3, Rollup, vitest (node environment, `TZ=America/Chicago`); Python 3.14 and Home Assistant 2026.10.0 in Docker for the dev Home Assistant, with backend tests from pytest-homeassistant-custom-component in Docker (`scripts/test-backend.sh`).

**Spec:** `docs/superpowers/specs/2026-10-12-kiosk-mode-design.md` (decisions D1 to D6, sections 3.1 to 3.3, 4, 5).

## Plan rulings

Every module and every test in Tasks 1 to 6 was built and run on a scratch branch before this plan was written (1108 backend tests and 1252 frontend tests at the end, each task's tests run at its own commit), and each screen was checked on the dev Home Assistant. These rulings were made while building it.

- **R1. Shared means marked shared.** Kiosk mode applies to accounts marked shared in Settings (`account.shared`), not to the "other" accounts the PIN rules also treat as shared screens. The owner's words were "shared family screens", and an unmarked account may be someone's own login.
- **R2. A step out runs by parent mode's clock, counted page-wide (D4).** The card's own session locks when the card leaves the screen (`SessionController.hostDisconnected`), so tying the step out to it would bring kiosk mode back the moment a parent opened one of Home Assistant's pages. The controller keeps its own clock with the session's quiet time and cap, counting `pointerdown` and `keydown` anywhere on the document; Lock, Back to kiosk mode, and a hidden page end it at once.
- **R3. Settings' section is Shared screens.** The switch applies to every shared screen, so it isn't under This screen (which is about the account in front of you). The design document records this.
- **R4. Settings draws its own strip, and it gets the same kiosk button.** The prototype's walkthrough found Settings' strip with only Lock while the card's had Exit kiosk mode; `pv-settings` takes `kioskAction` from the card and hands `pv-kiosk` back.
- **R5. Only undo what we did.** The controller turns Home Assistant's kiosk switch off only if it turned it on (the Companion app or an add-on may have set it).
- **R6. Tabs only hides `.action-items`;** Home Assistant's own kiosk switch already hides `ha-menu-button` on every panel, so the sidebar can't be opened from any header.
- **R7. `--pv-under-status-bar` exists only under Hidden,** set on `hui-root`'s host by the controller's sheet; the card adds it to its height, moves up by it, and pads its header by it. Everywhere else it is 0.
- **R8. The controller follows the page once a second** (the connection, the dashboard root, and a step out's end) and twice after `location-changed`; a check costs a few element lookups along Home Assistant 2026.10's own path (`home-assistant` > `home-assistant-main` > `ha-panel-lovelace` > `hui-root`).
- **R9. A refused Exit says why,** with the backend's words (`KIOSK_REFUSALS`) in a toast the card hosts itself.
- **R10. Dev checks of the admin case** link Blair's member to `person.dev` (the `dev` admin) only for their duration and put `person.blair` back.

```python
"""Kiosk mode (milestone 9): the household's setting, and who may step out of it.

On shared family screens the card hides Home Assistant's sidebar and header
(the top bar entirely, or all but its tabs). A parent whose own Home
Assistant login is an admin may step out while in parent mode. These rules
are pure; the WebSocket layer works out the facts.
"""
from __future__ import annotations

from collections.abc import Mapping
from typing import Any

KIOSK_TOP_BARS = ("hidden", "tabs")


def default_kiosk() -> dict[str, Any]:
    """Off, and when it's turned on, Home Assistant's top bar is hidden too."""
    return {"enabled": False, "top_bar": "hidden"}


def normalize_kiosk(value: object) -> dict[str, Any]:
    """The stored setting with missing or unknown values reset. Unknown fields are kept."""
    kiosk: dict[str, Any] = dict(value) if isinstance(value, Mapping) else {}
    if not isinstance(kiosk.get("enabled"), bool):
        kiosk["enabled"] = False
    if kiosk.get("top_bar") not in KIOSK_TOP_BARS:
        kiosk["top_bar"] = "hidden"
    return kiosk


def exit_refusal(*, enabled: bool, shared: bool, parent_session: bool, parent_is_admin: bool) -> str | None:
    """Why stepping out of kiosk mode is refused, or None when it may go ahead (spec D3)."""
    if not enabled:
        return "kiosk_off"
    if not shared:
        return "not_shared"
    if not parent_session:
        return "parent_mode_required"
    if not parent_is_admin:
        return "not_admin"
    return None
```

/**
 * Kiosk mode (milestone 9, docs/superpowers/specs/2026-10-12-kiosk-mode-design.md).
 * On a shared family screen with the household's switch on, Home Assistant's
 * sidebar is hidden (its own kiosk switch) and so is its dashboard header, or
 * all of it but the tabs. A parent who is a Home Assistant admin may step
 * out for as long as parent mode would last. These rules are pure; the
 * page-wide controller (shell/kiosk-controller.ts) applies them.
 */
import type { HouseholdView } from './household';

export type KioskLook = 'off' | 'hidden' | 'tabs';

/** What this screen looks like: off unless it is a shared screen and the switch is on (D1, D2). */
export function kioskLook(view: HouseholdView | null): KioskLook {
  const kiosk = view?.security.kiosk;
  if (!view?.account.shared || !kiosk?.enabled) return 'off';
  return kiosk.top_bar === 'tabs' ? 'tabs' : 'hidden';
}

/**
 * The style added to the dashboard's root (`hui-root`'s shadow root). For
 * Hidden: no header, no room kept for it, and the card runs up under the
 * status bar. For Tabs only: the header's buttons go, its tabs stay. If Home
 * Assistant renames these parts, the rules match nothing and the header
 * simply shows: kiosk mode fails open.
 */
export const KIOSK_SHEETS: Record<Exclude<KioskLook, 'off'>, string> = {
  hidden: [
    '.header { display: none !important; }',
    ':host { --header-height: 0px; --pv-under-status-bar: var(--safe-area-inset-top, 0px); }',
  ].join('\n'),
  tabs: '.action-items { display: none !important; }',
};

/** A step out of kiosk mode, by parent mode's own clock (D4). */
export interface StepOut {
  /** The last touch anywhere on the page (ms). */
  lastTouch: number;
  /** Lock after no touches (ms). */
  idleMs: number;
  /** When parent mode would end however busy (ms since the epoch). */
  capAt: number;
}

export function startStepOut(now: number, idleMs: number, capAt: number): StepOut {
  return { lastTouch: now, idleMs, capAt };
}

export function stepOutTouched(out: StepOut, now: number): StepOut {
  return { ...out, lastTouch: now };
}

export function stepOutEndsAt(out: StepOut): number {
  return Math.min(out.lastTouch + out.idleMs, out.capAt);
}

export function stepOutOver(out: StepOut, now: number): boolean {
  return now >= stepOutEndsAt(out);
}

/**
 * Kiosk mode on every Home Assistant page (milestone 9, spec 3.2).
 *
 * PlanaVista's script loads on every page, so kiosk mode is applied here,
 * not by the card: tied to the card it would lift whenever another tab or
 * panel showed. On a shared screen with the household's switch on, it turns
 * on Home Assistant's own kiosk switch (the sidebar and its menu button go)
 * and adds a style to the dashboard's root that hides the header, or all of
 * it but the tabs. A parent who may step out lifts it by parent mode's own
 * clock, counted anywhere on the page (D4).
 */
import type { HouseholdView } from '../core/household';
import { HouseholdConnection, HouseholdSubscription } from '../core/household-client';
import { KIOSK_SHEETS, KioskLook, StepOut, kioskLook, startStepOut, stepOutOver, stepOutTouched } from '../core/kiosk';

/** What the controller needs from the page; the tests fake it. */
export interface KioskEnv {
  /** The dashboard root's shadow root now, or null on a page without a dashboard. */
  root(): object | null;
  /** Adds a style to a root; the handle changes its text or takes it away. */
  addSheet(root: object, css: string): { set(css: string): void; remove(): void };
  /** Home Assistant's own kiosk switch (the sidebar and its menu button). */
  setHaKiosk(enable: boolean): void;
  haKiosk(): boolean;
}

export class KioskController {
  private _view: HouseholdView | null = null;
  private _stepOut: StepOut | null = null;
  private _applied: { root: object; handle: { set(css: string): void; remove(): void }; css: string } | null = null;
  /** We turned Home Assistant's switch on, so we may turn it off; someone else's we leave alone. */
  private _haOn = false;
  private _last: { look: KioskLook; out: boolean } = { look: 'off', out: false };
  private readonly _listeners = new Set<() => void>();

  constructor(private readonly _env: KioskEnv) {}

  /** off, hidden, or tabs, as the household says for this screen. */
  get look(): KioskLook {
    return kioskLook(this._view);
  }

  /** A parent stepped out and Home Assistant's menus show for now. */
  get steppedOut(): boolean {
    return this._stepOut !== null;
  }

  /** Hear when the look or the step out changes (the card's strip). */
  onChange(listener: () => void): () => void {
    this._listeners.add(listener);
    return () => this._listeners.delete(listener);
  }

  setView(view: HouseholdView | null): void {
    this._view = view;
    if (this.look === 'off') this._stepOut = null;
    this.sync();
  }

  /** Step out until the quiet time passes without a touch, or the cap (D4). */
  lift(now: number, idleMs: number, capAt: number): void {
    if (this.look === 'off') return;
    this._stepOut = startStepOut(now, idleMs, capAt);
    this.sync();
  }

  /** Back to kiosk mode: Back to kiosk mode, Lock, or a hidden page. */
  restore(): void {
    if (!this._stepOut) return;
    this._stepOut = null;
    this.sync();
  }

  /** A touch anywhere on the page keeps a step out going. */
  touch(now: number): void {
    if (this._stepOut) this._stepOut = stepOutTouched(this._stepOut, now);
  }

  /** Ends a step out whose time is up. */
  tick(now: number): void {
    if (this._stepOut && stepOutOver(this._stepOut, now)) this.restore();
  }

  /** Makes the page match: the current dashboard root styled, Home Assistant's switch on, or neither. */
  sync(): void {
    const look = this.look;
    const wanted = look !== 'off' && !this._stepOut;
    const root = wanted ? this._env.root() : null;
    if (this._applied && (!wanted || this._applied.root !== root)) {
      this._applied.handle.remove();
      this._applied = null;
    }
    if (wanted && root) {
      const css = KIOSK_SHEETS[look];
      if (!this._applied) this._applied = { root, handle: this._env.addSheet(root, css), css };
      else if (this._applied.css !== css) {
        this._applied.handle.set(css);
        this._applied.css = css;
      }
    }
    if (wanted && !this._env.haKiosk()) {
      this._env.setHaKiosk(true);
      this._haOn = true;
    }
    if (!wanted && this._haOn) {
      this._env.setHaKiosk(false);
      this._haOn = false;
    }
    const now = { look, out: !!this._stepOut };
    if (now.look !== this._last.look || now.out !== this._last.out) {
      this._last = now;
      this._listeners.forEach(listener => listener());
    }
  }
}

type HassElement = HTMLElement & { hass?: { connection?: unknown; kioskMode?: boolean } };

/** The dashboard's root, along Home Assistant 2026.10's own path; null anywhere else. */
function dashboardRoot(): ShadowRoot | null {
  const ha = document.querySelector('home-assistant');
  const main = ha?.shadowRoot?.querySelector('home-assistant-main');
  const lovelace = main?.shadowRoot?.querySelector('ha-panel-lovelace');
  return lovelace?.shadowRoot?.querySelector('hui-root')?.shadowRoot ?? null;
}

const browserEnv: KioskEnv = {
  root: () => dashboardRoot(),
  addSheet: (root, css) => {
    const shadow = root as ShadowRoot;
    const sheet = new CSSStyleSheet();
    sheet.replaceSync(css);
    shadow.adoptedStyleSheets = [...shadow.adoptedStyleSheets, sheet];
    return {
      set: next => sheet.replaceSync(next),
      remove: () => {
        shadow.adoptedStyleSheets = shadow.adoptedStyleSheets.filter(s => s !== sheet);
      },
    };
  },
  setHaKiosk: enable => window.dispatchEvent(new CustomEvent('hass-kiosk-mode', { detail: { enable } })),
  haKiosk: () => (document.querySelector('home-assistant') as HassElement | null)?.hass?.kioskMode === true,
};

/** The page's one controller; the card's strip uses it to step out and back. */
export const kiosk = new KioskController(browserEnv);

const STARTED = '__planavistaKiosk';

/** Starts kiosk mode for this page, once even if the bundle loads twice. */
export function startKiosk(): void {
  const w = window as unknown as Record<string, unknown>;
  if (w[STARTED]) return;
  w[STARTED] = true;
  const subscription = new HouseholdSubscription(view => kiosk.setView(view));
  const follow = () => {
    const ha = document.querySelector('home-assistant') as HassElement | null;
    subscription.update(ha?.hass?.connection as HouseholdConnection | undefined);
    kiosk.sync();
    kiosk.tick(Date.now());
  };
  window.setInterval(follow, 1000);
  follow();
  // A new panel or dashboard renders a moment after Home Assistant navigates.
  window.addEventListener('location-changed', () => {
    window.setTimeout(() => kiosk.sync(), 50);
    window.setTimeout(() => kiosk.sync(), 500);
  });
  const touched = () => kiosk.touch(Date.now());
  document.addEventListener('pointerdown', touched, true);
  document.addEventListener('keydown', touched, true);
  document.addEventListener('visibilitychange', () => {
    if (document.visibilityState === 'hidden') kiosk.restore();
  });
}
